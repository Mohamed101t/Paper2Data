# Paper2Data v1.0.0-rc.1

Paper2Data v1.0.0-rc.1 is the first public source release candidate for the Windows desktop MVP.

## What it does

Paper2Data helps users digitize paper forms and surveys through a guided form-entry interface instead of direct spreadsheet editing. Projects and records are stored locally and can be exported to Excel or CSV.

## Included

- offline SQLite storage;
- no-code field builder;
- 41 field types;
- required/type-aware validation;
- smart typed Excel export and CSV export;
- Arabic, English, French, Russian, and Chinese UI;
- Arabic RTL support;
- light/dark themes;
- searchable record management;
- spreadsheet-injection protection;
- unit, integration, security, E2E, GUI E2E, and performance test suites;
- Windows PyInstaller release tooling.

## Quality

The latest local Windows release-candidate quality gate completed with **124 passing tests** before packaging.

## Windows binary note

This release candidate should be treated as source-first until the public Windows binary completes the chosen code-signing and final distribution smoke-test process. Do not publish an `UNVERIFIED` archive as the final v1.0.0 asset.
