# Roadmap

The roadmap prioritizes usability for non-technical data-entry users before expanding the product surface.

## v1.0 desktop MVP stabilization

- [x] Project CRUD
- [x] Dynamic field builder
- [x] 41-type field system
- [x] Local SQLite storage
- [x] Validation
- [x] Excel / CSV export
- [x] Five UI languages
- [x] Arabic RTL support
- [x] Light / dark theme
- [x] Unit / Integration / E2E / Security / Performance testing
- [x] Windows release tooling
- [ ] Public binary code signing
- [ ] Public release smoke validation

## Next product improvements

- [ ] Step-by-step project creation wizard
- [ ] Auto-save drafts and resume after interruption
- [ ] Pre-export review with validation/problem counts
- [ ] Project/form templates
- [ ] Undo/redo improvements
- [ ] Human-friendly advanced search and filters
- [ ] Excel import
- [ ] Advanced field settings: currency, units, scale bounds, auto-number formatting
- [ ] Safe calculated-field formula engine
- [ ] Accessibility and keyboard-navigation refinements

## Later

- [ ] Mobile client sharing the same data model
- [ ] Optional backup/sync strategy

## Explicitly after MVP

- OCR / camera extraction
- cloud platform features
- AI-assisted extraction or classification
- advanced statistical analysis

These features are intentionally delayed so Paper2Data remains a focused data-entry tool rather than becoming a complex spreadsheet replacement.
